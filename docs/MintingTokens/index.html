Minting Tokens

Mints a new asset to the player's wallet under the game's policy: an NFT (quantity 1, CIP-25 metadata) or a fungible native token (any quantity), from the same Minter component.

Playable build: going live by 2 November 2026.
This page will host a playable WebGL build on the Cardano preprod testnet, so anyone can try it free with test ADA (tADA) and a CIP-30 wallet such as Eternl set to Preprod. Until then, the dApp is shown working on mainnet in the demo video below.
