Cardano SDK for Unity: sample dApps

Three sample dApps built with the Cardano Game Development SDK for Unity. Each is a Unity scene plus prefabs you can drop into your own game.

Playable now on the Cardano preprod testnet (free test ADA, no real funds). To play: install a CIP-30 wallet such as Eternl, switch it to Preprod, and get free tADA from the Cardano testnet faucet. Try them in order: the Gated Access checkpoint is locked until you earn GameCoin in Awarding Tokens. The demo video shows all three working on mainnet.
Gated Access
A checkpoint that reads the connected wallet on-chain and opens only if it holds a required token or NFT (any asset under a policy, a specific asset, quantity thresholds, or AND/OR/NOT rule groups).Awarding Tokens
Sends existing native tokens from a treasury wallet to the player when they complete something in the game. The player signs for the fee; the treasury signs to release the tokens.Minting Tokens
Mints a new asset to the player's wallet under the game's policy: an NFT (quantity 1, CIP-25 metadata) or a fungible native token (any quantity), from the same Minter component.
